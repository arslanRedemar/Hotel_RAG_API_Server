API 엔드포인트

40+ 엔드포인트 — 모듈별 REST API 카탈로그

/auth — 인증
POST/auth/login로그인 → Access + Refresh Token 발급
POST/auth/refreshAccess Token 갱신 (Refresh Rotation)
POST/auth/logout로그아웃 (Refresh 블랙리스트 등록)
GET/auth/me현재 인증 사용자 정보
/rag — RAG Assistant
POST/rag/query자연어 질의 → RAG 답변 + 출처 인용
POST/rag/documents/upload문서 업로드 (PDF/DOCX/TXT)
GET/rag/documents문서 목록 (부서 필터, 페이지네이션)
DEL/rag/documents/{id}문서 소프트 삭제
GET/rag/documents/{id}/versions버전 이력 조회
POST/rag/documents/{id}/acknowledge직원 확인 서명
/sop — SOP Digitalization
POST/sop/uploadSOP 이미지/PDF 업로드 → OCR 비동기 처리
GET/sopSOP 목록 (상태/부서 필터)
GET/sop/{id}SOP 상세 + 구조화 내용
PUT/sop/{id}/status상태 변경 (APPROVED/REJECTED)
GET/sop/{id}/exportPDF 내보내기 (reportlab)
POST/sop/{id}/acknowledge직원 확인 서명
/work-orders — Work Order Automation
POST/work-orders고장 신고 생성 (AI 분류 + 자동배정 트리거)
GET/work-orders목록 (상태/긴급도/담당자/부서 필터)
GET/work-orders/{id}상세 + 타임라인
PUT/work-orders/{id}/status상태 업데이트 (in_progress/done…)
POST/work-orders/{id}/assign수동 재배정
POST/work-orders/{id}/comments코멘트 + 사진 첨부
GET/work-orders/analytics카테고리별 분석, SLA 달성률, 패턴 분석
/compliance — Compliance & Audit
GET/compliance/schedules점검 스케줄 목록 (캘린더용)
POST/compliance/schedules스케줄 수동 생성
POST/compliance/records점검 실시 시작 (record 생성)
PUT/compliance/records/{id}/items/{item_id}항목별 OK/NG + 사진
POST/compliance/records/{id}/complete점검 완료 처리
GET/compliance/reports/{id}/pdf감사 보고서 PDF 생성
GET/compliance/anomalies이상감지 결과 목록
/revenue — Revenue Management
GET/revenue/dashboardKPI 대시보드 (ADR/OCC/RevPAR)
POST/revenue/metrics/manualPMS 미연동 시 수동 데이터 입력
POST/revenue/competitor-rates경쟁사 요율 수동 입력
GET/revenue/recommendationsAI 요율 권고 목록 (승인 대기)
POST/revenue/recommendations/{id}/approve요율 권고 승인 (Manager 이상)
POST/revenue/forecast수요 예측 실행 (Prophet/XGBoost)
POST/revenue/group-simulation단체 예약 수락/거절 시나리오 시뮬레이션

구현 로드맵

4단계 구현 계획 — Phase 0 완료 → Phase 4까지

0
Phase 0 — 기반 구축 완료
  • FastAPI 기본 서버 구성
  • ChromaDB 연동
  • PDF/TXT 문서 인덱싱
  • 기본 RAG 쿼리 (GPT-4o-mini)
1
Phase 1 — 핵심 기능 4~6주
  • JWT 인증 (Access + Refresh + Blacklist)
  • DOCX 문서 처리 (python-docx)
  • Work Order AI 분류 + 자동배정 (GPT)
  • SOP OCR 파이프라인 (Tesseract + OpenCV)
  • 점검 스케줄 자동 생성 (Celery Beat)
  • MySQL 전체 스키마 마이그레이션 (Alembic)
  • 부서별 권한 제어 (RBAC)
  • 파일 저장소 (S3 Presigned URL)
2
Phase 2 — 고도화 6~10주
  • Next.js 14 프론트엔드 전체
  • PWA + Service Worker + IndexedDB 오프라인
  • Web Push 알림 (VAPID)
  • SOP 검토 워크플로우 상태머신
  • 이상감지 엔진 (AnomalyDetector)
  • reportlab PDF 보고서 (한글 NanumGothic)
  • WebSocket 실시간 Work Order 대시보드
  • QR 코드 신고 기능
3
Phase 3 — 수익 관리 10~14주
  • PMS API 연동 (직접 연동)
  • Facebook Prophet 수요 예측
  • XGBoost 다변량 예측 모델
  • AI 요율 권고 엔진 (GPT + 룰 기반 가드레일)
  • 경쟁사 요율 수집 (Celery Beat)
  • 단체 예약 시뮬레이터
  • 예측 정확도 트래커 (MAPE)
4
Phase 4 — 안정화 14~16주
  • Google Vision API (고품질 OCR 대체)
  • Circuit Breaker 전체 적용
  • 구조화 JSON 로그 + 메트릭 (p50/p95/p99)
  • GitHub Actions CI/CD (test → lint → build → deploy)
  • 부하 테스트 (Locust)
  • Rate Limiting (로그인 시도 제한)
  • HTTPS + CORS 정책 (프로덕션)

보안 체크리스트

✅ 계획됨

🔐 JWT Refresh Token Rotation + 블랙리스트
🔑 bcrypt 패스워드 해시 (cost factor 12)
👤 Role-Based Access Control (Admin/Manager/Staff)
🔗 Presigned URL (직접 S3 접근 방지)
📋 불변 감사 로그 (audit_logs)
🛡️ SQL Injection 방지 (SQLAlchemy ORM)
📁 파일 업로드 검증 (MIME + 확장자 + 크기)

⏳ Phase 4 예정

⏱️ Rate Limiting (로그인 시도 제한)
🔒 HTTPS 전용 (프로덕션)
🌐 CORS 정책 (허용 Origin 화이트리스트)
🔄 Circuit Breaker (외부 API 장애 격리)
📊 보안 헤더 (CSP, HSTS, X-Frame-Options)
