# Revenue Management Support — 수익 관리 의사결정 지원 요구사항

> **영역**: AX 솔루션 의사결정 지원 영역
> **우선순위**: 중간 (P2)
> **작성일**: 2026-03-29
> **버전**: 2.0

---

## 1. 배경 및 맥락 (Context)

### 1-1. 현재 상황

Revenue Manager가 아침에 출근하면 가장 먼저 하는 일은 어제 예약 현황을 PMS에서 확인하고, OTA 사이트를 하나씩 열어서 경쟁사 요율을 직접 비교하고, 엑셀 시트를 업데이트하는 것이다. 이 과정에 매일 1~2시간이 소요된다. 그리고 이 시간이 지나면 그제야 "오늘 요율을 어떻게 할까"를 고민하기 시작한다.

**현재 수익 관리 업무의 실태**

| 업무 | 현재 방식 | 소요 시간 | 문제점 |
|------|---------|---------|------|
| 예약 픽업 현황 확인 | PMS 로그인 → 수동 조회 | 30분 | 어제 데이터, 실시간 아님 |
| 경쟁사 요율 비교 | OTA 사이트 4~5개 직접 확인 | 40분 | 편향적 샘플링, 일부 미확인 |
| 수요 예측 | 경험 + 직감 + 작년 같은 기간 메모 | - | 정량적 근거 없음 |
| 요율 결정 | 개인 판단 | - | 의사결정 근거 기록 없음 |
| 단체 예약 수락/거절 | 경험적 판단 | 수분~수십분 | 기회비용 계산 불가 |
| 성과 보고 | 엑셀 수동 작성 | 2~3시간/주 | 오류 가능성, 최신화 지연 |

### 1-2. 현재 의사결정의 구조적 문제

**정보 사일로 (Information Silos)**

수익 관리에 필요한 데이터가 4개 이상의 시스템에 분산되어 있다:
- PMS: 예약·점유율·ADR (내부 시스템, 수동 Export 필요)
- OTA 포털: 경쟁사 요율 (사이트별 개별 접속)
- 엑셀 파일: 과거 성과·예측 (개인 컴퓨터에 저장)
- 이벤트 캘린더: 수동 확인 (담당자 개인 숙지)

이 정보들을 하나로 모아서 판단에 활용하는 데 하루 2시간 이상이 소모된다.

**늦은 의사결정**

객실 요율 결정이 하루 1~2번으로 제한되어 있다. 오전에 요율을 올렸는데 오후에 픽업이 급감해도 저녁에야 파악하게 되는 구조다. 반대로 경쟁사가 갑자기 요율을 내렸는데 몇 시간이 지나도록 대응하지 못하는 경우가 발생한다.

**단체 예약 의사결정의 불확실성**

단체 80객실, 3박 요청이 들어왔을 때 수락하면 개별 예약 기회를 얼마나 잃는지 계산할 방법이 없다. 결국 "비슷한 시기에 얼마나 팔렸었지?"라는 기억에 의존하여 협상하게 된다.

### 1-3. 이해관계자별 고통 포인트

**Revenue Manager**
- 매일 아침 데이터 수집·정리에 소요되는 시간이 너무 많아 정작 전략적 판단에 시간을 쓰지 못함
- 요율 결정의 근거를 사후에 설명하기 어려움 (기록이 없음)
- AI 도입을 원하지만 "어떤 근거로 AI가 그 요율을 권고했는지" 설명 가능해야 함

**총지배인**
- 수익 성과가 좋을 때 "왜 잘됐는지", 나쁠 때 "무엇이 문제였는지" 파악 불가
- 단체 예약 승인 시 데이터 기반 협상 근거 없이 감으로 결정
- 경쟁 호텔 대비 RevPAR 격차가 벌어지는 원인 파악 불가

**예약팀 직원**
- 단체 문의가 왔을 때 Revenue Manager가 자리를 비우면 기다려야 함
- 요율 변경 승인 프로세스가 느려 기회를 놓치는 경우 발생

### 1-4. 기회 규모

업계 데이터에 따르면 AI 기반 수익 관리 도입 시:
- RevPAR 최대 35% 개선 가능 (글로벌 사례)
- Revenue Manager의 데이터 수집 업무 70% 이상 자동화 가능
- 요율 반응 속도 향상으로 수요 급증 시 수익 극대화

200실 규모 호텔의 경우, RevPAR 10% 개선만으로도 연간 수천만 원 이상의 추가 수익이 발생한다.

## 2. 문제 정의 (Problem Statement)

> **"어떻게 하면 Revenue Manager가 매일 아침 데이터 수집에 쓰는 2시간을 없애고, 분산된 PMS·OTA·이벤트 데이터를 하나의 대시보드에서 통합하여 AI 권고 기반의 신속한 요율 결정을 지원할 수 있을까?"**

---

## 3. 성공 비전 (Vision of Success)

도입 후 6개월 시점의 기대 모습:

- Revenue Manager가 출근하면 어제 픽업 현황·경쟁사 요율·AI 권고 요율이 대시보드에 이미 준비되어 있음
- 요율 결정을 대시보드에서 클릭 한 번으로 처리 (PMS 연동 자동 반영)
- 단체 예약 문의가 오면 5분 이내에 수락/거절 시나리오별 기대 수익을 계산하여 협상 가능
- AI 권고를 수락한 의사결정의 실적 기여가 사후에 추적·검증 가능

## 6. 핵심 의사결정 시나리오

### 시나리오 A — 수요 급증 감지 시 즉각 요율 대응
```
트리거: 특정 날짜 픽업 속도가 과거 동기간 대비 3배 이상 급증 감지

AI 분석:
  - 원인 파악: 해당 날짜 근처 대형 콘서트 이벤트 등록 확인
  - 경쟁사 현황: 경쟁사 A·B 이미 80% 이상 판매, C는 요율 유지 중
  - 잔여 재고: 해당 날짜 40% 잔여

권고:
  - 요율 +15% 인상 권고
  - LOS 2박 이상 제한 권고
  - 근거: "콘서트 D-14, 경쟁사 A·B 매진 임박, 픽업 3.2배"

담당자 처리:
  - 수락 클릭 → PMS 연동으로 자동 요율 변경 (P2)
  - 또는 수정하여 적용

수락 기준:
  - 급증 감지 → 권고 생성까지 1시간 이내 (다음 스케줄러 실행 시)
  - 권고 근거가 자연어 설명으로 제공됨
```

### 시나리오 B — 저수요 기간 프로모션 결정
```
트리거: 30일 후 예측 점유율이 목표(65%) 하회 — 현재 예측 42%

AI 분석:
  - 픽업 페이스가 동기간 대비 50% 낮음
  - 경쟁사 3곳이 이미 5~10% 할인 운영 중
  - 해당 기간 이벤트 없음

권고:
  - 특정 OTA 채널 한정 7% 할인 패키지 제안
  - 또는 조식 포함 패키지로 ADR 희생 최소화
  - 근거: "30일 후 픽업 부진, 경쟁사 할인 대응 필요"

수락 기준:
  - 예측 점유율 목표 하회 시 자동으로 알림 + 권고 생성
  - 권고에 대안 2개 이상 제시
```

### 시나리오 C — 단체 예약 수락 여부 즉각 판단
```
입력: 단체 80객실, 4/15~17 (2박), 제시 요율 12만원/박

AI 계산:
  수락 시 확정 수익: 80객실 × 2박 × 12만원 = 1.92억
  거절 시 기대 수익: 예측 점유율 75% × 200객실 × 2박 × ADR 14.5만원 = 4.35억
  → 단, 단체 없이 해당 80객실만: 80 × 2 × 75% × 14.5만원 = 1.74억

결론: 수락 시 +0.18억 우위, 단 취소 패널티 강화 조건부 권고

수락 기준:
  - POST 후 3초 이내 시나리오별 수치 반환
  - 기회비용이 숫자로 명시됨
```

## 8. 사용자 시나리오

```
As a Revenue Manager,
I want to 출근 후 대시보드에서 어제 픽업 현황과 오늘 AI 권고 요율을
          30초 만에 파악하고 싶다,
So that 매일 아침 2시간짜리 수동 데이터 수집·정리 작업을 없앨 수 있다.
```
