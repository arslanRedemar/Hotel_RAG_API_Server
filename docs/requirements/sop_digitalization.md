# SOP 자동 구조화 및 디지털화 요구사항

> **영역**: AX 솔루션 핵심 기회 영역 2
> **우선순위**: 높음 (P1)
> **배경**: 체크인/아웃 SOP, 하우스키핑 체크리스트, 야간감사 절차서 등 핵심 운영 문서가 PDF·종이·이메일에 흩어져 있으며 버전 관리가 되지 않아 직원마다 다른 버전의 절차를 따르는 서비스 불일치가 발생함.

---

## 1. 기능 요구사항

### 1-1. 레거시 문서 수집 및 OCR

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| SOP-F01 | 시스템은 스캔된 종이 문서(이미지 PDF)를 OCR 처리하여 텍스트로 변환할 수 있어야 한다 | P0 |
| SOP-F02 | 이미 디지털화된 PDF(텍스트 레이어 포함)는 OCR 없이 직접 텍스트 추출을 수행해야 한다 | P0 |
| SOP-F03 | 한국어, 영어 혼용 문서를 모두 처리할 수 있어야 한다 | P0 |
| SOP-F04 | 테이블, 체크리스트, 번호 목록 등 구조화된 레이아웃을 인식하여 보존해야 한다 | P1 |

### 1-2. AI 기반 구조 추출

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| SOP-F10 | AI는 원문 문서에서 절차(단계), 주의사항, 담당자, 소요시간 항목을 자동으로 추출해야 한다 | P0 |
| SOP-F11 | 추출된 절차는 번호가 매겨진 순서형 단계(Step 1, Step 2 …) 형태로 구조화되어야 한다 | P0 |
| SOP-F12 | 문서 내 체크리스트 항목은 체크박스 형태의 디지털 체크리스트로 변환되어야 한다 | P1 |
| SOP-F13 | AI 추출 결과에 대해 담당자가 수동 수정 및 검토 후 확정 처리를 할 수 있어야 한다 | P0 |
| SOP-F14 | 추출 정확도가 낮은 항목에는 "검토 필요" 플래그를 자동으로 표시해야 한다 | P1 |

### 1-3. 디지털 SOP 편집 및 관리

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| SOP-F20 | 담당자는 웹 인터페이스에서 구조화된 SOP를 직접 편집할 수 있어야 한다 | P1 |
| SOP-F21 | SOP 항목에 이미지, 동영상 링크를 첨부할 수 있어야 한다 | P2 |
| SOP-F22 | SOP를 PDF 또는 체크리스트 형태로 출력(Export)할 수 있어야 한다 | P1 |
| SOP-F23 | 부서, 직무, 시나리오별로 SOP를 분류·태깅할 수 있어야 한다 | P1 |

### 1-4. 버전 관리 및 변경 알림

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| SOP-F30 | 모든 SOP 변경 이력(작성자, 변경 일시, 변경 내용 요약)이 기록되어야 한다 | P0 |
| SOP-F31 | SOP 업데이트 시 해당 부서 직원에게 변경 내용 요약과 함께 알림이 발송되어야 한다 | P1 |
| SOP-F32 | 직원은 새 버전의 SOP를 확인했음을 시스템 내에서 확인(Acknowledge)할 수 있어야 한다 | P1 |
| SOP-F33 | 관리자는 부서 내 SOP 확인율(%)을 조회할 수 있어야 한다 | P2 |

## 2. 비기능 요구사항

| ID | 요구사항 | 기준 |
|----|---------|------|
| SOP-NF01 | OCR 처리 속도 | A4 1페이지 기준 5초 이내 |
| SOP-NF02 | OCR 정확도 | 표준 인쇄체 한국어 문서 기준 95% 이상 |
| SOP-NF03 | 구조 추출 정확도 | 절차형 문서에서 단계 추출 정확도 85% 이상 |
| SOP-NF04 | 저장 형식 | 구조화된 SOP는 JSON 또는 Markdown 형태로 저장 |

## 3. 대상 문서 유형

### 운영 절차 문서 (자동화 최우선)
- 체크인/아웃 SOP
- 하우스키핑 청소 체크리스트 (객실 유형별)
- 야간감사(Night Audit) 절차서
- 고객 컴플레인 처리 매뉴얼
- 화재/비상 대응 절차
- VIP 응대 프로토콜
- 식음료(F&B) 서비스 기준

### 인사 & 교육 문서 (디지털화 필요)
- 직무 기술서(Job Description)
- 신입 온보딩 가이드
- 서비스 스탠다드 매뉴얼
- 브랜드 규정집
- 성과 평가 기준표

## 5. 사용자 시나리오

```
As a 운영 매니저,
I want to 종이로 된 레거시 SOP를 스캔하여 업로드하면 AI가 단계별로 정리해주길 원한다,
So that 수작업 디지털화 없이 최신 SOP를 직원에게 배포할 수 있다.

As a 하우스키핑 슈퍼바이저,
I want to 객실 유형별 청소 체크리스트를 모바일로 불러와 실시간 체크할 수 있길 원한다,
So that 청소 완료 기준을 일관되게 유지할 수 있다.

As a 신입 직원,
I want to 온보딩 가이드를 단계별로 확인하고 완료 표시를 할 수 있길 원한다,
So that 무엇을 배웠는지, 무엇이 남았는지 스스로 추적할 수 있다.
```
