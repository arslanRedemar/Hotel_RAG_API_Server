# SOP 자동 구조화 및 디지털화 요구사항

> **영역**: AX 솔루션 핵심 기회 영역 2
> **우선순위**: 높음 (P1)
> **작성일**: 2026-03-29
> **버전**: 2.0

---

## 1. 배경 및 맥락 (Context)

### 1-1. 현재 상황

호텔 운영의 품질은 SOP(Standard Operating Procedure)의 일관된 실행에 달려 있다. 그러나 현재 이 SOP들이 어떻게 관리되고 있는지를 살펴보면 체계적 디지털화가 전혀 이루어지지 않고 있음을 알 수 있다.

**현재 SOP 관리 실태 (내부 현황 조사 기준)**

| 문서 유형 | 보관 형태 | 직원 접근 방식 | 마지막 업데이트 |
|---------|---------|------------|-------------|
| 체크인/아웃 절차 | 프린트 바인더 (프런트 데스크 서랍) | 직접 꺼내서 확인 | 2년 전 |
| 하우스키핑 체크리스트 | 객실 유형별 종이 양식 (하우스키핑 룸) | 종이 체크 후 보관 | 알 수 없음 |
| 야간감사 절차 | 담당자 개인 노트 + 구두 인수인계 | 인수인계 시 구두 전달 | 담당자 의존 |
| 고객 컴플레인 처리 | 이메일 스레드에 첨부 | 이메일 검색 | 매니저별 상이 |
| 비상 대응 절차 | 로비 게시판 + 종이 매뉴얼 | 비상 시 찾아봄 | 미확인 |
| F&B 서비스 기준 | 조리장 개인 보관 | 구두 전달 | 인사이동 시 단절 |

### 1-2. 핵심 문제 현상

**문제 1: 직원마다 다른 절차를 따른다**

신입 직원이 2명이 있을 때 둘이 배우는 체크인 절차가 다를 수 있다. 한 명은 1년 전 퇴직한 선임에게 배운 절차를, 다른 한 명은 현재 담당자에게 구두로 배운 절차를 따른다. 결과적으로 같은 호텔에서 고객마다 다른 서비스 경험을 받게 된다.

실제 발생 사례 유형:
- VIP 웰컴 어메니티 배치 기준: 직원 4명이 4가지 방식으로 진행
- 체크아웃 후 분실물 처리: 신고 채널이 직원마다 다름
- 룸서비스 트레이 회수 절차: 어떤 직원은 즉시, 어떤 직원은 요청 시에만 회수

**문제 2: SOP 변경이 현장에 도달하지 않는다**

매니저가 절차를 변경해도 기존 종이 매뉴얼이 여전히 유통되고 있다. 변경 공지가 카카오톡 단체방이나 이메일로 발송되지만 읽지 않거나 기억하지 못하는 경우가 많다.

**문제 3: 종이 기반 체크리스트의 감사 증거 부재**

하우스키핑이 청소를 완료했다는 종이 기록은 보관 기간이 짧고, 분실 위험이 있으며, 실제로 누가 언제 어떤 항목을 확인했는지 사후 검증이 불가능하다. 브랜드 감사나 외부 인증 심사 시 이 기록을 제출하기가 어렵다.

### 1-3. 이해관계자별 고통 포인트

**운영 매니저**
- 종이 SOP를 디지털로 옮기는 작업을 "지금 당장 중요하지 않아서" 계속 미룬다
- 신규 직원 온보딩 시 매번 직접 설명해야 한다 (1인당 2~3시간 소요)
- SOP 준수율을 수치로 보여줄 방법이 없다

**슈퍼바이저**
- 팀원이 절차를 잘못 따랐을 때 "어디서 배웠느냐"를 소급 확인할 수 없다
- 체크리스트 기록이 제대로 됐는지 확인하러 다니는 것이 업무 시간의 20% 이상
- 모바일로 실시간 확인하고 싶으나 현재 도구가 없다

**신입 직원**
- "어디에 SOP가 있는지" 자체를 모르는 상태에서 업무 투입
- 궁금한 게 있어도 선임에게 물어보는 것이 눈치 보임
- 온보딩 첫 2주 동안 실수로 인한 심리적 부담이 큼

### 1-4. 비즈니스 임팩트

- **서비스 불일치 비용**: 컴플레인의 약 35%가 "직원마다 응대가 다르다"는 서비스 불일치에서 발생 (추정)
- **교육 비용**: SOP 미존재·미전달로 인한 반복 교육이 연간 교육 비용의 40% 차지
- **브랜드 리스크**: 체인 호텔의 경우 SOP 미준수 시 브랜드 감사에서 패널티 부과 가능
- **직원 온보딩 효율**: 체계적 SOP 제공 시 온보딩 기간 50% 단축 가능 (업계 사례 기준)

## 2. 문제 정의 (Problem Statement)

> **"어떻게 하면 지금까지 종이·구두로만 존재하던 운영 절차들을 직원 누구나 모바일로 즉시 조회·실행·확인할 수 있는 디지털 SOP 시스템으로 전환하되, 레거시 문서를 수작업 없이 AI가 자동으로 구조화하여 도입 장벽을 최소화할 수 있을까?"**

---

## 3. 성공 비전 (Vision of Success)

도입 후 3개월 시점의 기대 모습:

- 전체 핵심 SOP(20건 이상)가 디지털화되어 모바일에서 조회 가능
- 신입 직원이 선임 도움 없이 SOP를 읽고 체크리스트를 완수할 수 있음
- 매니저가 SOP 변경 후 전 직원 확인율(%)을 실시간으로 대시보드에서 확인
- 브랜드 감사 요청 시 디지털 체크리스트 완료 기록을 즉시 PDF로 출력 가능

## 8. 사용자 시나리오

### 시나리오 A — 레거시 종이 SOP의 AI 디지털화
```
상황: 운영 매니저가 2년 된 인쇄본 체크인 SOP를 디지털화하려 함.
      수작업 입력 없이 자동화하고 싶음.

As a 운영 매니저,
I want to 종이 SOP를 스캔하여 업로드하면 AI가 단계별로 자동 구조화해주길 원한다,
So that 타이핑 없이 1시간 이내에 디지털 SOP를 완성하고 직원에게 배포할 수 있다.

흐름:
1. PDF 스캔본 업로드 → OCR 처리 → AI 구조 추출 (자동)
2. 추출 결과 검토 페이지에서 review_required 항목 수동 확인
3. 수정 완료 후 "승인" 처리 → 직원 검색 대상 등록
4. 해당 부서 직원 전원에게 알림 발송 (자동)

수락 기준:
- OCR → AI 추출 전체 과정 5분 이내 완료
- 담당자의 수동 수정이 필요한 항목(review_required)이 명확히 표시됨
- 승인 처리 즉시 RAG Assistant에서 해당 SOP 내용 조회 가능
```

### 시나리오 B — 모바일 체크리스트 실시간 완료
```
상황: 하우스키핑 슈퍼바이저가 스위트룸 청소 후 체크리스트 확인

As a 하우스키핑 슈퍼바이저,
I want to 모바일로 스위트룸 청소 체크리스트를 불러와 항목별로 체크하고
          서명으로 완료 처리를 하고 싶다,
So that 종이 기록 없이도 완료 증거가 디지털로 남아 감사 시 제출 가능하다.

수락 기준:
- 체크리스트 로딩 2초 이내
- 체크 후 자동 저장 (미저장 상태 없음)
- 완료 처리 시 서명자 이름 + 타임스탬프 자동 기록
```

### 시나리오 C — SOP 변경 전달 추적
```
상황: 매니저가 컴플레인 처리 절차를 변경하고 전 직원 인지 여부를 확인해야 함

As a 운영 매니저,
I want to SOP 업데이트 후 7일이 지나도 확인하지 않은 직원 목록을 볼 수 있길 원한다,
So that 해당 직원에게 개별 재공지하여 서비스 불일치 리스크를 제거할 수 있다.

수락 기준:
- 확인율(%) 및 미확인 직원 목록 조회 가능
- 미확인 직원에게 재알림 발송 기능 제공
```
