# Compliance & Audit Automation — 컴플라이언스 및 감사 자동화 요구사항

> **영역**: AX 솔루션 핵심 기회 영역 4
> **우선순위**: 높음 (P1)
> **배경**: 위생, 안전, 소방 등 법적 의무 점검 기록이 종이·엑셀로 관리되어 누락 리스크가 높음. 외부 감사 시 수동으로 자료를 취합하는 데 많은 시간이 소요되며, 이상 패턴을 사전에 감지하는 체계가 없음.

---

## 1. 기능 요구사항

### 1-1. 디지털 점검 체크리스트 (Mobile Checklist)

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| CA-F01 | 점검 담당자는 모바일로 디지털 체크리스트를 불러와 항목별로 점검 결과(OK/NG/해당없음)를 기록할 수 있어야 한다 | P0 |
| CA-F02 | NG 항목 선택 시 사진 첨부 및 비고 입력이 필수로 요구되어야 한다 | P0 |
| CA-F03 | 점검 완료 후 담당자의 전자서명(이름 + 타임스탬프)이 자동으로 기록되어야 한다 | P0 |
| CA-F04 | 점검 유형별(위생, 안전, 소방, 객실 품질) 전용 체크리스트 템플릿을 관리할 수 있어야 한다 | P0 |
| CA-F05 | 체크리스트 항목에 관련 규정 조항 또는 SOP 링크를 첨부할 수 있어야 한다 | P1 |

### 1-2. 법정 점검 주기 관리

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| CA-F10 | 시스템은 법정 점검 항목별 주기(일간/주간/월간/분기/연간)를 설정하고 자동 스케줄을 생성해야 한다 | P0 |
| CA-F11 | 예정된 점검일 D-7, D-1에 담당자 및 관리자에게 사전 알림을 발송해야 한다 | P0 |
| CA-F12 | 예정일 내 점검이 완료되지 않으면 상위 관리자에게 미완료 경고 알림을 발송해야 한다 | P0 |
| CA-F13 | 점검 일정 현황판(캘린더 뷰)에서 완료/예정/지연 상태를 한눈에 볼 수 있어야 한다 | P1 |

### 1-3. 이상 징후 자동 감지

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| CA-F20 | AI는 점검 데이터에서 동일 항목의 반복적 NG 패턴을 감지하여 관리자에게 알림을 발송해야 한다 | P1 |
| CA-F21 | 특정 구역(층, 객실 블록)에서 이상 항목이 집중될 경우 구조적 문제로 플래그 처리해야 한다 | P1 |
| CA-F22 | 에너지 사용량(전기, 수도) 데이터와 연동하여 이상 급증 시 시설팀에 자동 알림을 발송해야 한다 | P2 |

### 1-4. 감사 보고서 자동 생성

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| CA-F30 | 외부 감사 대비 기간 내 점검 이력을 자동으로 집계하여 감사 보고서(PDF)를 생성할 수 있어야 한다 | P0 |
| CA-F31 | 보고서에는 점검 항목별 합격률, NG 이력, 조치 완료 여부가 포함되어야 한다 | P0 |
| CA-F32 | 점검 유형(위생/안전/소방)별, 기간별, 담당자별 필터를 적용하여 보고서를 생성할 수 있어야 한다 | P1 |
| CA-F33 | 관련 법규 기준 변경 이력을 관리하고 해당 변경이 체크리스트 항목에 반영되었는지 추적해야 한다 | P2 |

## 2. 비기능 요구사항

| ID | 요구사항 | 기준 |
|----|---------|------|
| CA-NF01 | 데이터 무결성 | 점검 기록은 제출 후 수정 불가 (수정 시 별도 정정 기록 추가) |
| CA-NF02 | 보존 기간 | 법정 점검 기록은 최소 5년 보존 (관련 법규 준수) |
| CA-NF03 | 오프라인 동작 | 모바일 앱은 인터넷 미연결 상태에서도 체크리스트 작성 후 재연결 시 자동 동기화 |
| CA-NF04 | 감사 추적 | 누가, 언제, 어떤 항목을 어떤 결과로 기록했는지 모든 행위가 로그로 남아야 함 |
| CA-NF05 | 보고서 생성 속도 | 1년치 데이터 기준 PDF 보고서 생성 30초 이내 |

## 5. 사용자 시나리오

```
As a 위생 담당 직원,
I want to 주방 위생 점검 체크리스트를 모바일로 불러와 실시간으로 기록하고 싶다,
So that 종이 기록 후 다시 PC에 입력하는 이중 작업을 없앨 수 있다.

As a 시설 관리자,
I want to 다음 달 소방 점검 일정이 자동으로 생성되고 D-7에 알림을 받고 싶다,
So that 법정 점검 누락으로 인한 과태료 리스크를 방지할 수 있다.

As a 총지배인,
I want to 외부 위생 감사 전에 최근 6개월 점검 이력 보고서를 한 번에 출력하고 싶다,
So that 감사 자료 준비에 소요되는 시간과 누락 리스크를 줄일 수 있다.

As a 운영 관리자,
I want to 특정 구역에서 NG 항목이 반복되면 즉시 알림을 받고 싶다,
So that 구조적 문제를 조기에 발견하고 선제적으로 대응할 수 있다.
```
