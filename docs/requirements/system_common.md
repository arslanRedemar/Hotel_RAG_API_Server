# System Common — 시스템 공통 요구사항

> **적용 범위**: 전체 AX 솔루션 공통
> **참조**: 모든 기능 요구사항 문서에서 이 문서를 공통 기준으로 인용

---

## 1. 인증 및 권한 관리

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| SYS-F01 | 모든 API 엔드포인트는 JWT 기반 인증을 요구해야 한다 (헬스 체크 제외) | P0 |
| SYS-F02 | 사용자 역할은 최소 Admin / Manager / Staff 3단계로 구분되어야 한다 | P0 |
| SYS-F03 | 부서(department) 속성을 기반으로 데이터 접근 범위를 제한할 수 있어야 한다 | P1 |
| SYS-F04 | 비밀번호는 bcrypt 이상의 단방향 해시로 저장해야 한다 | P0 |
| SYS-F05 | 로그인 실패 5회 이상 시 계정을 일시 잠금(30분)해야 한다 | P1 |

### 역할별 기본 권한

| 역할 | RAG 검색 | SOP 관리 | Work Order | 점검 기록 | 수익 대시보드 | 관리자 설정 |
|------|---------|---------|-----------|---------|------------|-----------|
| Admin | 전체 | R/W | 전체 | 전체 | 전체 | O |
| Manager | 부서 | R/W | 부서 | 부서 | 부서 | X |
| Staff | 부서 | Read | 본인/부서 | 본인 | X | X |

## 2. 알림 시스템

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| SYS-F10 | 시스템은 이메일, 앱 푸시 알림, SMS(선택) 채널을 지원해야 한다 | P1 |
| SYS-F11 | 알림 유형별로 수신 채널을 사용자가 직접 설정할 수 있어야 한다 | P2 |
| SYS-F12 | 알림 발송 실패 시 최대 3회 재시도하고 실패 이력을 기록해야 한다 | P1 |
| SYS-F13 | 모든 알림 발송 이력(대상, 채널, 시간, 성공/실패)이 조회 가능해야 한다 | P2 |

### 알림 트리거 목록

| 트리거 | 수신 대상 | 채널 |
|--------|---------|------|
| Work Order Critical 접수 | 시설팀 전원 + 관리자 | Push + Email |
| Work Order SLA 초과 | 상위 관리자 | Email |
| SOP 신규 버전 등록 | 해당 부서 직원 | Push + Email |
| 점검 예정일 D-7, D-1 | 담당자 | Email |
| 점검 미완료 경고 | 담당자 + 관리자 | Email |
| 이상 패턴 감지 | 관련 부서 관리자 | Push + Email |
